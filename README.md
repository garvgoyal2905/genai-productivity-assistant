# genai-productivity-assistant

Project Title: GenAI Productivity Assistant

Description: An AI-powered tool for summarizing text, extracting key topics, and generating questions.

Features:
-Summarization of text inputs
-Key topic extraction
-Automatic question generation

Technologies Used:
-IBM WatsonX.ai
-Python
-Streamlit
-HuggingFace Transformers

Installation Command:
git clone https://github.com/username/genai-productivity-assistant.git  
cd genai-productivity-assistant  
pip install -r app/requirements.txt  

Usage Command:
streamlit run app/app.py  

Example Command(arduino):
streamlit run app/app.py --server.port 8501
